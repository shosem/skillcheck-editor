# プログラミングスキルチェック用ランナー

問題集・スキルチェック系サイトの問題を、**自分の手元のブラウザで気持ちよく解くため**の、ブラウザだけで動く実行環境です。
HTML ファイル1つで動き、インストールやサーバーは不要です。

> 本ツールは個人が作成した非公式のツールで、特定のサービスとは関係ありません。

---

## 制作意図

問題集のサイトで練習していて、次の3点が不便だったので、解決するために作りました。

1. **予測変換で Enter を押すと、候補が適用されてしまう**
   問題集サイトのエディタでは、改行したいだけなのに、出ていた候補が確定されてしまうことがありました。
   → 本ツールでは、候補は **Tab で確定**し、**Enter は常に改行**です。予測変換は ON/OFF も切り替えられます。

2. **既存のオンライン実行環境では、標準入力が隠れている**
   標準入力の欄が折りたたまれていたり、実行のたびに入力し直す必要があったりして、手間でした。日本語に対応していない環境もありました。
   → 本ツールでは、**標準入力欄を常に表示**し、貼り付けた内容は実行のたびに自動で使われます。日本語も使えます。

3. **問題文をコメントアウトで用意するしかなかった**
   問題文を見ながら解くために、コードの先頭にコメントとして貼り付けるしかありませんでした。
   → 本ツールでは、問題文を **専用の欄にペーストするだけ**で、見出しや入力例を見やすく整形して表示します。

画面に出るのは、**問題文・標準入力（入力例）・コードエディタ・出力**の4つだけです。
正解かどうかの判定は、元の問題集サイト側で行うため、本ツールには判定機能はありません。

---

## 特長

- 言語とバージョンを選べます（Python、C++、Java、JavaScript、Ruby、Go、Rust、C# など）
- 言語ごとのシンタックスハイライト
- 問題文をペーストすると自動で整形
- 標準入力が常に表示され、実行のたびに自動で使われる
- 予測変換は **Tab で確定、Enter は常に改行**（ON/OFF 切替可）
- 括弧・引用符の自動補完、対応する括弧のハイライト
- 言語ごとの慣習に合わせたインデント幅（Ruby は2、Go はタブ、など）
- インデントの整形ボタンとショートカット
- ライト／ダークテーマ、問題文とコードで別々の文字サイズ
- 書いたコード・標準入力・問題文は、ブラウザに自動保存

## 使い方

### 1. 開く

`index.html`（または公開された URL）をブラウザで開きます。
初回は、エディタの部品などをネットから読み込むため、**インターネット接続が必要**です。

### 2. 画面の構成

| 場所 | 内容 |
| --- | --- |
| 左上 | **問題文**（ペーストすると整形表示） |
| 左下 | **標準入力**（常時表示・コピー＆ペースト可） |
| 右上 | **コードエディタ** |
| 右下 | **出力** |

各ペインの境界線は、**ドラッグして大きさを変えられます**。

### 3. 基本の流れ

1. ヘッダーで **言語** と **バージョン** を選びます。
2. 左上の問題文欄に、問題文を **ペースト** します。
3. 入力例が **標準入力欄に自動で入ります**（すでに入力があるときは入りません）。
4. 右上のエディタでコードを書きます。
5. **「実行」** を押すか、`Ctrl + Enter`（Mac は `Cmd + Enter`）で実行します。
6. 右下の出力欄で結果を確認します。

### 4. 問題文の欄

- ペーストすると、「問題」「入力される値」「条件」「入力例」「出力例」などの見出しを付け、フォーマットや入力例をコードブロックで見やすく表示します。
- **整形表示のまま、もう一度ペーストすると、問題文が新しいものに置き換わります。**
- **原文を編集 / 整形表示**: 貼り付けた原文を直したいときに切り替えます。
- **クリア**: 問題文を消します。
- **A− / A＋**: 問題文の文字サイズを変えます。
- 各入力例の右上の **標準入力へ**: その入力例を標準入力欄に入れます。

### 5. 標準入力の欄

- 好きな内容を貼り付けたり、書き込んだりできます。
- 実行のたびに、この内容が標準入力として使われます。末尾の改行は、足りなければ自動で付けます。
- **クリア**: 内容を消します。

### 6. コードの欄

| 操作 | 内容 |
| --- | --- |
| **インデントの整形**（`Shift+Alt+F`／Mac は `Shift+Opt+F`） | インデントを、選んだ言語の幅にそろえます。範囲を選択していればその範囲だけ、していなければ全体が対象です |
| **A− / A＋** | コード・標準入力・出力の文字サイズを変えます |
| `Tab` | 予測変換の候補があれば確定。なければインデントを入れます |
| `Enter` | 常に改行（予測変換は確定しません） |
| `Esc` | 予測変換の候補を閉じます |
| `Cmd + ←` ／ `Home` | 行頭へ移動。1回目は最初の文字の左、もう一度押すと0列目（交互に切り替わります） |
| `Ctrl/Cmd + Enter` | 実行 |

**インデントの整形について**
Python など、インデントが文の意味を決める言語（Python、Haskell、CoffeeScript、F#、Nim、Elixir）では、誤って意味を変えないよう、整形は行いません。
整えるのはインデントだけで、改行の位置や空白の入れ方は変わりません。

**言語ごとのインデント幅の既定値**
2スペース: Ruby、JavaScript、TypeScript、Haskell、Scala、Bash、SQL ほか／タブ: Go／それ以外: 4スペース。

### 7. 予測変換

- 2文字以上を打つと、**そのコードの中で既に使った変数・関数・クラス名**が候補として出ます。
- 確定は `Tab`、選択は `↑` `↓`、閉じるのは `Esc` です。
- ヘッダーの **予測変換: ON / OFF** ボタンで切り替えます。設定は保存されます。
- 日本語入力の変換中は、候補は出ません。

### 8. 括弧の補完

`(` `[` `{` `"` `'` を打つと、閉じ側が自動で入ります。`{` のあとに Enter を押すと、閉じ括弧が下の行に出て、中がインデントされます。対応する括弧は強調表示されます。

### 9. 出力の欄

- コンパイラの出力、標準出力、標準エラー出力、終了コード、かかった時間（通信を含む）を表示します。
- **コピー**: 出力をクリップボードにコピーします。

### 10. そのほか

- **ライト/ダーク**: テーマを切り替えます。
- コード、標準入力、問題文、選んだ言語・バージョン、各種設定は、ブラウザに自動で保存されます。

## 注意事項

- **実行時に、コードと標準入力が外部の実行サービス（[Wandbox](https://wandbox.org/)）へ送られます。** 外部に出したくない内容は入力しないでください。保存（共有リンクの作成）はしない設定です。
- 無料の共用サービスを使っているため、混雑や制限で、実行が遅くなったり失敗したりすることがあります。
- 問題文・コード・標準入力は、**自分のブラウザ（localStorage）にだけ保存**されます。サーバーには送られず、他の人からは見えません。ただし、**共用パソコンでは、前の人の内容が残る**場合があるため、使い終わったら「クリア」してください。
- 問題文の著作権や、利用している問題集サイトの利用規約に注意してください。**問題文や解答を、SNS・ブログ・公開リポジトリなどに載せないでください。** 本ツールは、貼った問題文を、自分のブラウザ内で整形して表示するだけです。
- 問題文の整形は、見出しが決まった形式の問題文を前提にした、簡易的な判定です。うまく整形されない場合があります。
